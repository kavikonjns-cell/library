# کتابخانه کاوی کنج

سیستم مدیریت کتابخانهٔ کودک و طبیعت «کاوی کنج» بر پایهٔ تلگرام: ربات تلگرام برای اعضا و مسئولان کتابخانه، به‌اضافهٔ سایت (فهرست زندهٔ کتاب‌ها و پنل مدیریت) و یک پایگاه دادهٔ کوچک که همهٔ اطلاعات را نگه می‌دارد.

## چه کار می‌کند؟

**برای عضو**

1. ربات را باز می‌کند و «📝 فرم عضویت» را می‌زند. فرم (همان فرم عضویت کتابخانه) داخل خود تلگرام باز می‌شود.
2. فرم را پر و ثبت می‌کند و **کد عضویت** (مثل `M-07`) فوراً در ربات صادر می‌شود، همراه با مبلغ حق عضویت و شمارهٔ کارت.
3. عکس فیش را در ربات می‌فرستد. فیش برای مسئول کتابخانه می‌رود و او با یک دکمه تأییدش می‌کند. از این لحظه عضویت فعال است.
4. «📚 فهرست کتاب‌ها» را باز می‌کند. روی هر کتاب وضعیت قفسه دیده می‌شود: «✅ موجود در قفسه»، «📕 در امانت تا ۱۴۰۵/۰۸/۱۹» یا «⏳ رزرو شده». تعداد نفرهای صف انتظار هم نشان داده می‌شود.
5. «درخواست امانت» را می‌زند و **مدت امانت** را انتخاب می‌کند (۷، ۱۰ یا ۱۴ روز).
6. ربات درخواست را بررسی می‌کند و نتیجه را می‌گوید:
   - اگر عضویت معتبر نیست، حق عضویت تأیید نشده، کتاب دیگری در دست دارد یا جریمهٔ پرداخت‌نشده دارد، دلیلش را می‌گوید.
   - اگر کتاب موجود باشد، برای او **رزرو** می‌شود تا ظرف ۳ روز از باغ شبنم تحویل بگیرد.
   - اگر کتاب در امانت باشد، می‌گوید تا چه تاریخی دست کس دیگری است و او را در **صف انتظار** می‌گذارد. وقتی کتاب برگشت، خودکار برای نفر بعدی رزرو می‌شود و ربات خبرش می‌کند.
7. ربات دو روز قبل از مهلت و روز آخر یادآوری می‌فرستد. «🔁 تمدید امانت» تا سقف ۳۰ روز از روز تحویل کار می‌کند، به شرط اینکه کسی در صف انتظار همان کتاب نباشد.

**برای مسئول کتابخانه**

- پیام عضو تازه، فیش‌ها و رزروها با دکمه‌های «✅ تأیید پرداخت»، «✅ تحویل داده شد» و «📥 برگشت» در تلگرام می‌رسند.
- دستورهای ربات: `/admin`، `/loans`، `/lend NS-012 M-07 14` (امانت حضوری)، `/return NS-012`، `/member M-07`، `/find`، `/daily`.
- پنل وب در `‎/admin`: داشبورد، امانت‌ها، اعضا (ثبت فرم کاغذی، تمدید، ابطال)، کتاب‌ها (افزودن و ویرایش)، حسابداری (دفتر صندوق).
- خروجی **اکسل** با برگه‌های کتاب‌ها، اعضا، امانت‌ها، صف انتظار و حسابداری.
- خروجی **HTML فهرست کتاب‌ها**: یک فایل تک‌تکه مثل فهرست قبلی، برای گذاشتن در گروه تلگرام. وقتی با اینترنت باز شود، وضعیت قفسه را از سایت به‌روز می‌کند.

**قوانین خودکار** (از روی فرم عضویت و فایل اکسل کتابخانه)

| قانون | پیاده‌سازی |
|---|---|
| هر عضو یک کتاب | درخواست دوم رد می‌شود. عضو فقط می‌تواند به صف انتظار برود. |
| مدت ۱۴ روز، با تمدید حداکثر ۳۰ روز | `LOAN_DEFAULT_DAYS`، `LOAN_MAX_INITIAL_DAYS`، `LOAN_MAX_TOTAL_DAYS` |
| بدون تمدید اگر کسی در صف باشد | بررسی می‌شود. |
| جریمه ۵۰ هزار تومان در روز، حداکثر ۴ روز | هنگام ثبت برگشت حساب می‌شود و تا تسویه نشود امانت تازه ممکن نیست. |
| ابطال عضویت با ۵ روز تأخیر | بررسی روزانه (ساعت ۹ صبح به وقت تهران)، با پیام به عضو و مسئول |
| گم شدن یا آسیب جدی | جریمه ندارد. نسخه از قفسه خارج می‌شود تا نسخهٔ جایگزین برسد. |
| اعتبار تا پایان اسفند (از دی به بعد: تا اسفند سال بعد) | خودکار، با یادآوری یک هفته پیش از پایان |
| حق عضویت ۶۰۰ / ۸۰۰ / ۱۰۰۰ هزار تومان بر اساس نقش | `FEE_STAFF`، `FEE_PARENT`، `FEE_OTHER` |
| نسخهٔ دوم (مثل `NS-012-2`) | در فهرست یک بار می‌آید. اگر نسخهٔ اول در امانت باشد، نسخهٔ دوم داده می‌شود. |

## راه‌اندازی

### ۱. ساخت ربات
در تلگرام به `@BotFather` بروید، با `/newbot` ربات بسازید و توکن را بردارید. شناسهٔ عددی مسئولان را از `@userinfobot` بگیرید.

### ۲. سرور
- سرور باید **خارج از ایران** باشد، چون از داخل ایران به API تلگرام دسترسی نیست.
- یک دامنه (یا زیردامنه) لازم است. فرم عضویت و فهرست کتاب‌ها داخل تلگرام فقط روی **HTTPS** باز می‌شوند.

```bash
git clone https://github.com/sub7mehrdad-a11y/kavikonj.git
cd kavikonj
cp .env.example .env        # توکن، دامنه، شناسهٔ مسئولان و رمز پنل را بنویسید
nano Caddyfile              # دامنهٔ خودتان را به‌جای kavikonj.example.com بگذارید
docker compose up -d --build
```

Caddy گواهی HTTPS را خودکار می‌گیرد. سایت روی `https://دامنه‌شما/` و پنل روی `https://دامنه‌شما/admin` است.

**بدون Docker:**
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m app.main          # روی پورت 8000؛ جلوی آن یک nginx یا Caddy با HTTPS بگذارید
```

### ۳. کتاب‌ها
فهرست فعلی (۸۰ نسخه، ۷۸ عنوان، با معرفی و عکس جلد) در `data/seed/books.json` و `app/static/covers/` آماده است و در اولین اجرا خودکار وارد می‌شود. برای به‌روزرسانی از روی فایل اکسل کتابخانه:

```bash
python scripts/import_books.py "کتابخانه.xlsx" "فهرست کتاب‌ها.html"
```

کتاب تازه را هم می‌توانید از پنل (کتاب‌ها ← کتاب تازه) اضافه کنید. عکس جلد را با نام کد کتاب (مثل `NS-079.jpg`) در `app/static/covers/` بگذارید.

### ۴. فونت (اختیاری)
برای اینکه سایت با فونت «BHoma» فرم‌ها نمایش داده شود، `BHoma.ttf` را در `app/static/fonts/` بگذارید. اگر این فایل نباشد، فونت آزاد «وزیرمتن» استفاده می‌شود.

## اعضایی که فرم کاغذی پر کرده‌اند
در پنل، بخش اعضا ← «ثبت عضو با فرم کاغذی» کد عضویت صادر می‌شود. عضو بعداً در ربات «🔗 قبلاً عضو شده‌ام» را می‌زند و کد عضویت و شمارهٔ تماسش را می‌فرستد (مثلاً `M-07 09121234567`) تا تلگرامش وصل شود.

متنی که فرم HTML قبلی می‌ساخت («📝 درخواست عضویت در کتابخانه کاوی کنج ...») هم اگر در ربات فرستاده شود، خوانده می‌شود و کد عضویت صادر می‌شود. کد کتاب (مثل `NS-012`) یا پیام «می‌خواهم کتاب ... با کد NS-012 را امانت بگیرم» هم کار می‌کند.

## ساختار پروژه

```
app/
  config.py        تنظیمات و قوانین (از .env قابل تغییر)
  services.py      منطق کتابخانه: عضویت، رزرو، امانت، صف، جریمه، تمدید، بررسی روزانه
  bot.py           ربات تلگرام
  web.py           سایت، API مینی‌اپ تلگرام، پنل مدیریت
  exporter.py      خروجی اکسل و HTML
  db.py            پایگاه دادهٔ SQLite (فایل data/kavikonj.db)
  templates/       صفحه‌ها
  static/          استایل، لوگو، جلد کتاب‌ها
scripts/import_books.py
tests/             آزمون‌ها: python -m pytest
```

**پشتیبان‌گیری:** همهٔ اطلاعات در فایل `data/kavikonj.db` است. یک نسخه از آن (یا خروجی اکسل پنل) را مرتب جای امنی نگه دارید.
